# OOPS Lab - C++

By Asad Khan

C++ programs for the Object Oriented Programming lab, experiments 1 to 10, plus the mini project.

## Experiments

| No. | File | Topic |
|-----|------|-------|
| 1 | exp01.cpp | Data types, constants, variables, operators, I/O |
| 2 | exp02.cpp | Class hierarchy, access specifiers, member functions |
| 3 | exp03.cpp | Constructors and Rule of 5 |
| 4 | exp04.cpp | Single and multilevel inheritance |
| 5 | exp05.cpp | Runtime polymorphism (virtual functions, abstract class) |
| 6 | exp06.cpp | Function and operator overloading |
| 7 | exp07.cpp | Templates (generic Stack) |
| 8 | exp08.cpp | STL containers and algorithms |
| 9 | exp09.cpp | Custom exceptions (banking) |
| 10 | exp10.cpp | File I/O with CSV (seekg, seekp, tellg, tellp) |
| 11 | miniproject.cpp | Student Management System |

## Mini Project: Student Management System

A menu-driven program to add, view, search, update and delete student records. It uses two classes, `Student` and `StudentManager`, and stores the records in a `vector` in memory.

## How to run

```
g++ exp01.cpp -o exp01
./exp01
```

On Windows PowerShell, use `.\exp01` instead of `./exp01`.
